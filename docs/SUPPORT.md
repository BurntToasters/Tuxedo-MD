# Support

Tuxedo MD has no account inside the app. Help is through the public GitHub repository [BurntToasters/Tuxedo-MD](https://github.com/BurntToasters/Tuxedo-MD). Use that repository to report a problem or ask a question.

Community builds are the GitHub downloads for Windows and macOS. Official Linux builds are published on GitHub as well, and those builds include the Pro capabilities at no charge. Pro is the store build, distributed through the Mac App Store and Microsoft Store.
